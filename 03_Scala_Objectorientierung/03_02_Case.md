
# 1 Case Klassen

Case Classes sind der Shortcut, wenn man schnell und bequem Klassen bauen will.
spezielle Klassen, die automatisch um bestimmte Methoden und Felder erweitert werden, z.b. toString, apply und unapply Methoden. dadurch wird Pattern Matching sehr erleichtert

- Eine **Case-Klasse** ist eine spezielle Art von Klasse in Scala, die vor allem für immutable Datenstrukturen gedacht ist
- Sie wird häufig in der funktionalen Programmierung verwendet, um Daten auf deklarative Weise zu modellieren
- Standardgemäß sind die Daten einer Case-Klasse unveränderlich, aber öffentlich zugreifbar (`**public**`)
- Eine Case-Klasse wird automatisch mit Methoden `**toString**`, `**==**`, `**hashCode**` und `**copy**` und mit Pattern Matching ausgestattet
- Für jede Case-Klasse erzeugt der Compiler automatisch ein Companion-Objekt mit der Methoden `**apply**` und `**unapply**`
- `**toString**` erzeugt aus dem Namen der Klasse und ihren Klassenparametern einer Zeichenkette
- `**copy**` erlaubt das einfache Erzeugen veränderter Kopien eines Objektes, welches von der Case-Klasse instanziiert wurde
- `**==**` und `**hashCode**` ermöglichen einen Vergleich zweier Objekte
- `**apply**` ist eine Factory-Methode zur Instanziierung eines Objektes der Case-Klasse



```
val p1 = Product("123", "Wireless Mouse", "Accessories", 29.99)
val p2 = Product.apply("456", "TrackPad", "Accessories", 39.99)

val discounted = p1.copy(price = p1.price * 0.9)
println(p1.toString)
println(p1 == p2)
println(p1.hashCode == p2.hashCode)

```


Wenn man `case` vor eine Klasse schreibt, bekommt man automatisch:
- `toString`, `equals`, `hashCode`, `copy` alles generiert
- ein **Companion Object** mit `apply` und `unapply` Methoden


```
case class Employee(name: String, age: Int, income: Int)

val person: Employee = Employee("Loris", 23, 420)

person match {
  case Employee(name, _, income) if (income > 419) =>{
    name + " do you want to donate?"
  }

  case _ => "This person does not meet the donation criteria."
}

println(person) //Employee(Loris,38,420)
```



- Eine case Klasse mischt der Klasse den Trait `ProductN` bei, wobei N für die Anzahl der Klassenparameter der case Klasse steht
- ProductN verfügt über Methoden wie productArity,  productElement und productElementName, mit denen der Compiler automatisch die einzelnen Elemente eines Objektes extrahieren kann


Dadurch kann der Compiler automatisch alle Felder extrahieren (wie hier income):
```
person match {
  case Employee(name, _, income) if income > 419 => ...
}
//age wird hier bewusst ignoriert! 
```

## 1.2 Case Klassen 的原理 :    Trait `**ProductN**`

- Eine `**case**`-Klasse mischt der Klasse den Trait `**ProductN**` bei, wobei `**N**` für die Anzahl der Klassenparameter der `**case**`-Klasse steht
- `**ProductN**` verfügt über Methoden wie `**productArity**`, `**productElement**` und `**productElementName**`, mit denen der Compiler automatisch die einzelnen Elemente eines Objektes extrahieren kann
- Mit `**val Product(id, name,...)=p**` kann man dann Objekte einer Case-Klasse elegant zerlegen, danach stehen die Felder als eigenständige Variablen zur Verfügung
- Die Extraktor-Funktion wird auch beim Pattern Matching (nächster Abschnitt verwendet)
- Bemerkung: In Scala2 wurde die Extraktorfunktionalität in `**case**`-Klassen noch durch die Methode `**unapply**` implementiert – in Scala3 gibt diese lediglich das Objekt selbst zurück
- `**unapply**` kann jedoch in nicht-`**case**`-Klassen händisch für die Zerlegung implementiert werden



```
case class Employee(name: String, age: Int, income: Int)

val person: Employee = Employee("Loris", 23, 420)

person match {
  case Employee(name, _, income) if (income > 419) =>{
    name + " do you want to donate?"
  }

  case _ => "This person does not meet the donation criteria."
}

println(person) //Employee(Loris,23,420)
```

## 1.3 例子


1. Was ist der Unterschied zwischen case classes und regulären classes in Scala?
2. Erstellen Sie jeweils case Klassen zu den Geometrischen Formen Kreis, Rechteck
und dreieck welche alle notwendigen Informationen beinhalten um die Fläche der
jeweiligen Geometrischen Form zu berechnen.
3. Implementieren Sie die Methode calculateArea die eine Instanz dieser geometrischen
Formen übergeben bekommt und die Fläche dieser berechnet und zurückgibt.
4. erweitern Sie die Methode calculateArea so, dass keine geometrischen Formen mit
Parametern kleiner gleich 0 akzeptiert werden.

![](image/Pasted%20image%2020250601190834.png)

```
case class Circle(radius: Double)
case class Rectangle(width: Double, height: Double)
case class Triangle(base: Double, height: Double)

def calculateArea(shape: Any): Double = shape match {
  case Circle(radius) => Math.PI * Math.pow(radius, 2)
  case Rectangle(width, height) => width * height
  case Triangle(base, height) => 0.5 * base * height
  case _ => throw new IllegalArgumentException("Invalid shape.")
}

def calculateArea(shape: Any): Double = shape match {
  case Circle(radius) if radius > 0 => Math.PI * Math.pow(radius, 2)
  case Rectangle(width, height) if width > 0 && height > 0 => width * height
  case Triangle(base, height) if base > 0 && height > 0 => 0.5 * base * height
  case _ => throw new IllegalArgumentException("Invalid shape.")
}
```




# 2 Case-Objekte


- Ein **case-Objekt** ist eine Singleton-Variante einer `**case class**`
- Es ist ein einzelnes, benanntes, unveränderliches Objekt, dass sich wie eine `**case class**` verhält, aber keine Parameter und (natürlich) kein Companion-Objekt besitzt
- Es verfügt über automatisch erzeugte Methoden `**toString**`, `**equals**` und `**hashCode**`
- Es wird für die Darstellung konkreter Zustände oder abgeschlossener Alternativen im Rahmen von algebraischen Datentypen (siehe spätere Folien) verwendet


```
sealed trait OrderStatus

case object Open extends OrderStatus
case object Shipped extends OrderStatus
case object Completed extends OrderStatus
case object Cancelled extends OrderStatus


println(Cancelled.toString)
println(Cancelled == Cancelled)
println(Cancelled == Shipped)
println(Cancelled.hashCode)
println(Shipped.hashCode)


```
